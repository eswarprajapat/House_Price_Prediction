🏠 House Price Prediction System

A full-stack machine learning web application that predicts real estate prices based on various property features. This project integrates a trained Machine Learning model with a user-friendly web interface to provide instant price estimations.

Key Features

*  High Accuracy: The model delivers reliable predictions with an accuracy of approximately 80%.

*  Interactive Web Interface: Built with HTML, CSS, and JavaScript, allowing users to easily input property details (e.g., square footage, location, number of bedrooms).

*  Real-time Predictions: Powered by a Flask backend that processes user input and serves predictions instantly.

*  Data Visualization: Includes exploratory data analysis to understand price trends.
